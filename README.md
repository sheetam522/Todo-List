Client-Side Todo List Application

Objective:
The objective of this project is to create a simple and responsive Todo List web application that helps users manage their daily tasks. The application runs entirely in the browser and allows users to add, complete, and delete tasks while storing the data locally using browser storage.
Project Description
The Client-Side Todo List Application is a web-based task management tool built using HTML, CSS, and JavaScript. It allows users to create and organize tasks efficiently.
Users can add tasks using an input field, mark them as completed when finished, and delete tasks when they are no longer needed. The application also includes filtering options to view all tasks, only active tasks, or completed tasks.
The tasks are stored using the browser's localStorage, ensuring that the tasks remain available even after refreshing or closing the browser.

Technologies Used:
HTML5 – for structuring the web page
CSS3 – for styling and responsive design
JavaScript (Vanilla JS) – for application logic and interaction
localStorage – for storing tasks in the browser

Challenges Faced:
Some challenges faced while developing this project include:
Implementing task filtering (All, Active, Completed)
Managing data persistence using localStorage
Handling DOM updates dynamically when tasks are added or removed
Ensuring the application works properly on both desktop and mobile screens
